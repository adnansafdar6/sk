# Prompt 8 — Admin User Management

Create an Admin User Management page:

1. Table listing all users: ID, username, phone, balance, VIP level, status, join date, actions
2. Search/filter by username, phone, status, VIP level
3. **Actions per user**: View profile details (modal), Ban/Suspend/Activate toggle, Reset password, Change VIP level (dropdown), Manually adjust wallet balance (with reason field that creates a transaction record)
4. Pagination for the user list
5. Add to admin navigation/sidebar
