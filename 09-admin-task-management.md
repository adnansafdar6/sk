# Prompt 9 — Admin Task Management

Create an Admin Task Management page:

1. Table of all tasks: title, reward, daily limit, VIP level required, status, completions count
2. **"Create Task"** button opens a form: title, description, instructions (rich text or textarea), reward amount, daily limit per user, VIP level required (0=all), status (active/inactive)
3. Edit existing tasks inline or via modal
4. Activate/Deactivate toggle per task
5. Delete task (soft delete or hard delete with confirmation)
6. Show total completions and total USDT distributed per task

Add to admin sidebar.
